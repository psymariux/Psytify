# Icons

- **Iconly** (Light and Bold styles): home, search, heart, setting, people, user (account), video,
  voice (lyrics), volume, download, delete, edit, filter (equalizer). The paths come from the
  `react-iconly` 2.2.10 package (MIT license), read as SVG data: the project contains no JavaScript.
  The free Iconly set is by Piqo Design (https://iconly.pro/): if you redistribute it, check the
  license terms and credit the author.
- **Drawn for Psytify** with the same stroke (1.5px on 24px, round caps): play, pause,
  next, previous, shuffle, repeat, repeat-one, queue, library, plus, close, minimize, fullscreen,
  fullscreen-exit, chevron-right, chevron-left, chevron-down, keyboard, check, more, note, list, mark, bell, bell-fill, moon, expand, copy,
  radio, sparkle, user-plus, chart.

The icons are white: Iced tints them when drawing (`ui/icons.rs`).
